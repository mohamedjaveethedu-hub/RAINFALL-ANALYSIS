🌧️ Rainfall Data Analysis Project

📌 Overview

This project analyzes district-wise rainfall data to uncover patterns, trends, and key insights. The goal is to demonstrate practical data analysis skills using Python.

---

🎯 Objectives

- Identify districts with the highest rainfall
- Analyze rainfall trends across different time periods
- Compare rainfall distribution among districts

---

🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib

---

📂 Project Structure

rainfall-analysis-project/
│
├── data/
│   └── rainfall.csv
│
├── outputs/
│   ├── top5_rainfall.png
│   └── monthly_trend.png
│
├── analysis.py
├── README.md
├── requirements.txt

---

📊 Key Analysis

1. Top Rainfall Districts

- Calculated total rainfall for each district
- Identified top 5 districts with highest rainfall

2. Monthly Rainfall Trends

- Computed average rainfall across months
- Visualized trend using line chart

3. Comparative Analysis

- Compared rainfall distribution among top districts

---

📈 Outputs

The project generates the following visualizations:

- Bar chart of top 5 rainfall districts
- Line chart showing monthly rainfall trends

(All outputs are saved in the "outputs/" folder)

---

▶️ How to Run

1. Clone the repository:

git clone <your-repo-link>

2. Navigate to project folder:

cd rainfall-analysis-project

3. Install dependencies:

pip install -r requirements.txt

4. Run the script:

python analysis.py
